# 수학 액티비티 Lab — 독립 테스트 앱

기존 Streamlit 대시보드와 별도로 실행하는 수업 활동 앱입니다. **새 GitHub 저장소와 새 Streamlit 앱**으로 실행해 주세요. 기존 앱에 파일을 덮어쓰거나 설정을 복사할 필요가 없습니다.

## 가장 빠른 시작

1. ZIP 압축을 풉니다.
2. 새 GitHub 저장소(예: `math-activity-lab`)를 만들고 압축 안의 파일과 폴더를 업로드합니다. 저장소 첫 화면에 **`app.py`와 `requirements.txt`**가 보여야 합니다.
3. Streamlit Community Cloud에서 이 새 저장소로 앱을 만듭니다. 실행 파일은 **`app.py`**, Python은 **3.12**를 선택합니다.
4. 처음에는 **Secrets를 입력하지 않아도 됩니다.** 로그인 화면과 가상 계정, 함수 예제 수업이 자동으로 준비됩니다.

| 역할 | 아이디 | 초기 비밀번호 |
|---|---|---|
| 교사 | `teacher` | `TeacherTest!2026` |
| 학생 25명 | `student01` ~ `student25` | `StudentTest!2026` |

모든 예제 학생은 `1-1`반입니다. 교사는 일반 창, 학생은 다른 브라우저 또는 시크릿 창에서 로그인하세요. 같은 브라우저의 일반 탭만 추가하면 로그인 상태가 혼동될 수 있습니다.

공개된 가상 계정으로 시험하는 버전이므로 실제 학생 정보는 넣지 마세요. 기본 저장은 앱 내부의 임시 파일이며, Cloud 재시작·재배포 등으로 초기화될 수 있습니다.

## 10분 테스트 순서

1. 교사로 로그인해 **활동 → 수업 운영**에서 예제 수업을 엽니다.
2. 다른 브라우저에서 `student01`로 로그인합니다. 이미 참여한 예제 수업을 선택합니다.
3. 학생이 서술형 답을 쓰고 그래프의 슬라이더·점을 움직입니다. 교사 화면에서 진행 상황과 답안이 갱신되는지 확인합니다.
4. 교사 화면에서 **전체 일시정지 → 활동 재개**를 누릅니다. 잠금 중에는 학생 답안을 수정할 수 없어야 합니다.
5. 진행 가능한 화면 범위를 줄이고, 같은 화면으로 모으기를 실행합니다.
6. `student02`도 별도 세션으로 참여해 같은 모둠의 공동 보드에 메모와 필기를 올립니다.
7. 학생이 답안의 공개 범위를 **우리 학급**으로 선택하면 교사가 해당 답안을 스냅샷으로 공유하고 발표 화면에서 비교합니다.
8. 교사가 개별 피드백을 남기고, 학생이 피드백을 확인합니다.
9. 교사가 수업을 마감한 뒤 다시 열어 봅니다. **학습 기록**에서 기록 파일을 내려받습니다.
10. **수업 만들기**에서 새 수업을 작성한 뒤 **수업 운영 → 반별로 새 수업 배포**를 실행합니다. 새 수업은 참여 코드로 들어갈 수 있습니다.

## 들어 있는 기능

| 영역 | 기능 |
|---|---|
| 수업 제작 | 화면 추가·복제·순서 변경, 질문·힌트·교사 평가 기준, PDF 페이지를 활동 화면으로 추가 |
| 학생 활동 | 서술형, 선택형, 그래프 탐구, 카드 분류, 좌표표, 그림·필기, PDF 위 필기 |
| 수업 참여 | 반별 배포, 참여 코드, 학생별 진행 상황, 자동 저장, 제출 |
| 교사 제어 | 전체 일시정지, 진행 범위 제한, 같은 화면으로 모으기, 마감·재개 |
| 피드백 | 교사 개별 피드백, 설정한 정답 기준에 따른 확인, 조건부 다음 화면 |
| 공유·협업 | 모둠 메모·필기 보드, 학생 공개 범위 선택, 익명 표시, 답안 스냅샷·발표 |
| 기록 | 답안 변경 이력, JSON·CSV·ZIP 내보내기 |
| 계정 | 독립 로그인, 학생 계정 생성, 비밀번호 변경·초기화 |
| 선택 기능 | 실제 API를 연결하는 텍스트·이미지·음성 AI 힌트 |

## 로컬 실행

Python 3.12 환경에서 이 폴더를 연 뒤 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

기본 데이터는 이 앱의 `lab_data/`에 저장됩니다. 기존 대시보드의 `data/`, `[app]`, `[github]` 설정은 읽지 않습니다.

## 선택 설정: 기록을 계속 보관하기

Streamlit Cloud의 Secrets에 아래 내용을 넣습니다. 토큰은 **별도로 만든 비공개 테스트 데이터 저장소**에 접근할 수 있어야 합니다. 해당 저장소의 Contents 읽기·쓰기 권한이 필요합니다.

```toml
[lab]
test_mode = true
storage = "github"
teacher_id = "teacher"
teacher_password = "직접-정한-8자-이상-비밀번호"

[lab_github]
repo = "내아이디/activity-lab-test-data"
branch = "main"
token = "테스트-저장소용-GitHub-토큰"
```

테스트 데이터는 `activity-lab/data/`, 첨부 파일은 `activity-lab/files/` 아래에 저장됩니다. GitHub 저장은 약 8초 단위로 모아서 처리합니다. 서버가 갑자기 종료되면 아직 반영하지 않은 변경은 유실될 수 있습니다. 같은 데이터 저장소를 여러 앱에서 동시에 사용하지 마세요.

저장 방식을 바꾸면 새 저장 공간에서 시작하며, 기존 로컬 데이터가 자동으로 이전되지는 않습니다. Secrets의 비밀번호는 최초 계정 생성에 사용합니다. 이미 만들어진 계정의 비밀번호를 바꾸려면 앱의 **내 비밀번호**를 사용하세요.

## 선택 설정: AI 힌트

API 키 없이도 나머지 수업 기능을 사용할 수 있습니다. AI를 시험하려면 교사의 공개 초기 비밀번호부터 바꾸고 Secrets에 다음을 추가합니다. 기존 `[lab]`이 있으면 그 아래에 항목을 추가하고, 같은 섹션을 두 번 작성하지 마세요.

```toml
[lab]
test_mode = true
storage = "local"
teacher_id = "teacher"
teacher_password = "직접-정한-8자-이상-비밀번호"

[openai]
api_key = "실제-OpenAI-API-키"
model = "gpt-4.1-mini"
transcribe_model = "gpt-4o-mini-transcribe"
```

이미 교사 계정이 있다면 앱의 **내 비밀번호**에서 직접 바꾸세요. 설정을 저장하고 앱을 재시작한 뒤 교사가 수업 운영에서 AI 사용을 열어 줍니다. 학생은 전송 동의를 선택하고 힌트를 요청합니다. 이때 답안·첨부 자료가 API로 전송되며 사용 비용이 발생합니다. 기본 공개 교사 비밀번호로는 AI가 활성화되지 않습니다.

`.streamlit/secrets.toml.example`에도 설정 예시가 있습니다. 실제 키·토큰을 넣은 Secrets 파일은 GitHub에 올리지 마세요.

## 현재 테스트 범위와 제한

- Python·Streamlit 자동 검사 31개, JavaScript DOM·수식 검사 12개가 통과했습니다. 자세한 내용은 `TEST_REPORT.md`에 있습니다.
- 실제 Streamlit Cloud 배포, iPad 필기, 마이크 권한, 외부 GitHub 저장, 실제 OpenAI 호출은 이 패키지에서 현장 확인이 필요합니다.
- 실시간 화면은 약 1.5초 간격 갱신입니다. 단일 서버 프로세스를 기준으로 만들었으며 여러 서버를 쓰는 대규모 운영은 지원하지 않습니다.
- 그래프는 기본 함수·음함수, `a/b/c` 슬라이더, 점과 표를 지원합니다. 표시 범위는 x=-10~10, y=-7~7입니다. Desmos 전체 수식 문법을 구현한 엔진은 아닙니다.
- PDF는 한 번에 8MB 이하·20쪽 이하, 수업은 최대 40화면입니다. 파일 첨부도 개당 8MB 이하입니다.
- `test_mode=false`는 기존 가상 계정을 삭제하지 않습니다. 실제 운영 전에는 새 데이터 저장 공간과 별도의 운영 인증 구성을 준비해야 합니다.
